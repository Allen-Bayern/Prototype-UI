Brutalist 是 Proto UI 贡献者原创并维护的 Neo-Brutalist 设计语言投射，使用方角几何、强边框、平涂填色、硬偏移阴影与高对比排版。它不是任何第三方组件系统的移植、兼容层或认证集成。

已发布的 `0.2.0-rc.7` package 汇集既有 Base family 投影——Button、Toggle、Switch、Tabs、Hover Card、Dropdown Menu、Select、Dialog、Scroll Area、Separator 与 Textarea——以及直接定义的 styled-only Badge、Card 与 Skeleton 原型。Textarea 是 Base Textarea 上的纯视觉投影。

下方每张卡片只展示一个基础 Demo，用于快速浏览组件范围与整体视觉；API 文档与代码示例保留在独立组件页。

## 状态

- 来源：贡献者原创 Proto UI style family，仅使用一般 Neo-Brutalist 视觉参考。
- 语义：Button、Toggle、Switch、Tabs、Hover Card、Dropdown Menu、Select、Dialog、Scroll Area、Separator 与 Textarea 投射各自的 Base 协议。Textarea 只增加 resize-y、方角薰衣草紫/ink、硬阴影视觉样式；Badge 与 Card 是没有 Base counterpart 的 direct passive styled-only prototype。Skeleton 是直接定义的 styled-only、passive、contentless 视觉原型，loading、announcement、替换时机与焦点连续性由父级拥有。
- 发布状态：已作为 40-package `0.2.0-rc.7` BOM 中的公开 package 发布，并可通过 npm `next` 获取；不可变发行证据见 [v0.2.0-rc.7 prerelease](https://github.com/Proto-UI/Proto-UI/releases/tag/v0.2.0-rc.7)。
- 已发布 package surface：root 以及 `./button`、`./badge`、`./card`、`./toggle`、`./switch`、`./tabs`、`./hover-card`、`./dropdown`、`./select`、`./dialog`、`./scroll-area`、`./separator`、`./skeleton`、`./textarea` subpath。
- 维护：rc.7 将其作为公开但非 launch-commitment 的 package 发布；后续语义变化与长期所有权仍由 Proto UI governance 决定。
