Brutalist Scroll Area 保留 Base 的宿主滚动面、归一化 viewport facts、orientation 与已解析 projection。它偏好 composed chrome，并增加方形 paper 表面和高对比 Lavender/ink 控件。Thumb 的尺寸与位置由家族级 host projection session 根据可见比例和滚动位置连续投射；自定义 track click 与 thumb drag 仍不属于当前 passing guarantee。

用于 ChatUI conversation history、会话列表、命令结果、日志和密集 SaaS 面板。外围 layout 必须给 Root 明确尺寸。
