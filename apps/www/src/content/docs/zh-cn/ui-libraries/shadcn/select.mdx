当前条目把 shadcn 风格与 API 表面组合在已经编目的 Base Select 协议之上，并在 Web Components、React、Vue 三种适配器中共享同一套选择、焦点和 ARIA 语义。

<PrototypePreviewer demoId="demo-shadcn-select" initialRuntime="wc" />

## 当前范围

- `Root`、`Trigger`、`Value`、`Content`、`Item`
- `defaultValue` / `value`、`defaultOpen` / `open` 与对应变更事件
- `Trigger.size="sm | default"`
- `Content.position="item-aligned | popper"`，默认值与 shadcn/ui 一致为 `item-aligned`
- 单选、禁用项、键盘导航、typeahead、浮层关闭与焦点恢复

`Group`、`Label`、`Separator`、`Viewport`、滚动按钮、`ItemText`、`ItemIndicator` 和表单提交仍在后续范围。Content 通过 Anchored Position host 投射的 anchor-size CSS 变量与 Trigger 动态等宽；当前 `item-aligned` 保留官方 API 与默认值，但几何实现仍复用 Base 的锚点定位，尚未实现 Radix 的逐项对齐算法。
