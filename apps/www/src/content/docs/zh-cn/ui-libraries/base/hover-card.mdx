Base Hover Card 由 Root、Trigger 与 Content 组成。Root 支持受控/非受控 open、`openDelay`、`closeDelay` 与 `openChange`；Content 使用 `asOverlay` 和 `asTransition`，离场完成后才 detach。当前定位 API 覆盖 `side` 与 `align`，portal、碰撞检测、Arrow、forceMount 和数值 offset 暂不属于 Base 保证。
