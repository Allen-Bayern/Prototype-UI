Brutalist is a Proto UI-maintained, contributor-authored Neo-Brutalist design-language projection built from square geometry, strong borders, flat color, hard offset shadows, and high-contrast typography. It is not a port, compatibility layer, or certified integration of any third-party component system.

The published `0.2.0-rc.7` package combines projections over existing Base families—Button, Toggle, Switch, Tabs, Hover Card, Dropdown Menu, Select, Dialog, Scroll Area, Separator, and Textarea—with direct styled-only Badge, Card, and Skeleton prototypes. Textarea is a visual-only projection over Base Textarea.

Each card below shows one basic demo for quickly browsing the component range and visual language. API documentation and code examples remain on the individual component pages.

## Status

- Provenance: contributor-authored Proto UI style family, with general Neo-Brutalist visual references only.
- Semantics: Button, Toggle, Switch, Tabs, Hover Card, Dropdown Menu, Select, Dialog, Scroll Area, Separator, and Textarea project their corresponding Base protocols. Textarea adds only resize-y, square lavender/ink, hard-shadow styling. Badge and Card are direct passive styled-only prototypes with no Base counterparts. Skeleton is a direct styled-only, passive, contentless visual prototype; its parent owns loading, announcements, replacement timing, and focus continuity.
- Release status: published as a public package in the 40-package `0.2.0-rc.7` BOM and available from npm under `next`; immutable release evidence is attached to the [v0.2.0-rc.7 prerelease](https://github.com/Proto-UI/Proto-UI/releases/tag/v0.2.0-rc.7).
- Published package surface: root plus `./button`, `./badge`, `./card`, `./toggle`, `./switch`, `./tabs`, `./hover-card`, `./dropdown`, `./select`, `./dialog`, `./scroll-area`, `./separator`, `./skeleton`, and `./textarea` subpaths.
- Maintenance: published in rc.7 as a public non-launch-commitment package; later semantic changes and long-term ownership remain subject to Proto UI governance.
